# Feature: Albergues y Recursos (Mobile)

## Responsabilidad
* Catálogo de albergues disponibles y puntos de asistencia humanitaria.
* Consulta de capacidad máxima vs ocupación actual.
* Registro de ingreso/egreso de personas albergadas (`shelter_stays`).
* Servicios disponibles (agua potable, atención médica, alimentos).
