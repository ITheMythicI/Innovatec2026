# Feature: Mapa Interactivo y Geolocalización (Mobile)

## Responsabilidad
* Renderizado de capas de mapa (OpenStreetMap / Mapbox / Flutter Map).
* Caché offline de teselas de mapa para operación sin conexión satelital.
* Marcadores para:
  - Albergues (con estatus de ocupación)
  - Zonas de riesgo activas (polígonos)
  - Puntos de interés y centros de acopio
  - Incidentes y eventos de rescate
