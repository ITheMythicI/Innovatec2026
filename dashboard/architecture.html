01

Capa de Clientes & Hardware

  • smartphone App Móvil (Flutter / Dart): Interfaz ciudadana y brigadistas en modo oscuro, botón SOS físico/virtual y base SQLite local.
  • gps_fixed Motor GPS Satelital: Geolocalización satelital directa mediante geolocator en el dispositivo real.
  • computer Dashboard Web C5: Centro de mando táctico, emisión de avisos y creación de zonas poligonales GeoJSON.
  • volume_up Sirenas & Nodos de Campo: Balizas acústicas de 115-120 dB activables remotamente vía LoRaWAN 915 MHz.
Tecnologías: Flutter 3.x, Dart, sqflite, Leaflet, Tailwind CSS.
02

Capa de Red Híbrida & Ruteo

  • wifi REST API / JSON: Conexión con failover multi-host (172.16.160.167:3001 / USB / LAN).
  • sensors Malla LoRaWAN (915 MHz): Protocolo RF cifrado con modulación de largo alcance para zonas sin cobertura celular.
  • bluetooth BLE Mesh P2P: Sincronización descentralizada de credenciales y pings "Estoy a Salvo" entre móviles.
  • route Servidor OSRM: Trazado vial dinámico de rutas seguras de evacuación desde el GPS real hasta el albergue.
Protocolos: HTTP/REST, LoRaWAN, BLE 5.0, OSRM API, AES-256.
03

Backend NestJS & Lógica de Negocio

  • dns Multi-Interface Binding: Servidor configurado en 0.0.0.0:3001 para acceso universal en LAN y Wi-Fi.
  • security Control de Acceso RBAC: JWT Guards con roles estrictos (SUPER_ADMIN, COMMANDER, OPERATOR, USER).
  • layers Módulos de Negocio: Geography (Polígonos 32-Point), Shelters, Emergencies, People, Devices y Broadcast.
  • check_circle Validación Global: Transformación estricta de DTOs con class-validator.
Tecnologías: NestJS, TypeScript, Node.js, Prisma ORM, Swagger.
04

Base de Datos & Motor Geoespacial

  • database PostgreSQL 16: Almacenamiento relacional ACID con contenedor Docker en puerto 5433.
  • public PostGIS 3.4 Spatial: Indexación R-Tree, cálculo de distancias exactas (ST_Distance) y radios (ST_DWithin).
  • polyline Polígonos GeoJSON: Almacenamiento nativo de perímetros de desbordamiento, fallas geológicas y zonas de riesgo.
  • sync Eventos de Sincronización: Cola de idempotencia para transacciones originadas offline.
Tecnologías: PostgreSQL 16, PostGIS 3.4, Docker Compose.
